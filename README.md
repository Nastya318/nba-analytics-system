#  NBA Predictive Analytics System



Прогнозно-аналитическая система для прогнозирования статистики игроков в баскетбол на основе исторических данных и актуального API.



##  Технологический стек:



- **Язык программирования**: Python 3.10+

- **Источники данных**: Kaggle Dataset (CSV, исторические данные), BALLDONTLIE API (REST JSON, актуальные данные)

- **Хранение данных**: SQLite / PostgreSQL (слоистая архитектура)

- **Обработка и ML**: pandas, scikit-learn, SQLAlchemy

- **Визуализация**: Streamlit

- **Оркестрация и автоматизация**: Python-скрипты (main.py), конфигурация через YAML и `.env`



##  Архитектура данных:



Система построена по принципам Data Engineering с явным разделением на слои хранения:



1\. **Raw Layer (Сырые данные)**: исходные данные из CSV-файлов Kaggle и JSON-ответов API сохраняются в неизменном виде.

2\. **Cleaned Layer (Очищенные данные)**: данные проходят валидацию, типизацию, обработку пропусков и дедупликацию (UPSERT по составному ключу `player\_id` + `game\_date`).

3\. **Analytics Layer (Витрины данных)**: агрегированные и обогащенные данные, готовые для обучения ML-моделей и питания дашбордов.
